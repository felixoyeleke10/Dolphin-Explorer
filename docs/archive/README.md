# Archive README

This folder holds historical docs that are still worth keeping, but should not be treated as the default active implementation path.

## What Lives Here

- `docs/archive/10_plan/`
  - completed stage plans kept for historical context
- `docs/archive/90_closure_notes/`
  - older per-slice and per-stage closure notes

## How To Use It

- use the main `docs/` tree for current control, planning, guides, and templates
- use this archive only when you need to understand why earlier work was structured a certain way
- do not treat archived stage plans as the current implementation source of truth unless a control doc explicitly says to do so

## Bottom Line

Archived docs are history, not the default active route.
